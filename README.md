# Gully Cricket — MVP foundation

Login-free, offline-first cricket scoring app for iOS and Android.

## Included in this starter
- Flutter application shell and navigation
- Local SQLite database for teams, players, matches and deliveries
- Manual ball-by-ball scoring engine
- Legal-ball handling for wides and no-balls
- Batting/bowling figures and innings totals
- Basic award-candidate calculations
- PDF match report generation

## Run
1. Install Flutter SDK and the iOS/Android toolchains.
2. Run `flutter create .` inside this folder if platform folders are not present.
3. Run `flutter pub get`.
4. Run `flutter run`.

This is the first MVP foundation, not a signed release build. Before public release, complete device testing and validate local cricket rules (especially run-outs, retired hurt, penalty runs and custom over rules).
